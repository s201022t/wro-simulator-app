## 試験変更

- 最大PWMを優先し、既定の最低PWM 100が最大値を引き上げないようにした。最大0は停止。
- 時間基準のS字加速（最大傾き600 PWM/秒）と残距離30%の減速の小さい方を左右輪の上限にした。
- 補正時は共通出力を下げ、どちらの輪も上限を超えないようにした。
- 初回は姿勢P=3.0、同期P=1.0・上限8 PWMにしたが、前後進ともカーブするとの実機報告を受け、補正計算を変更前（姿勢P=0.3、D=0.4、同期P=16.5・上限160 PWM、合成上限150 PWM）へ戻した。角度誤差による同期の減衰も廃止。
- ジャイロ異常後の再駆動を廃止した。
- 後退の動き始めの振動対策として、後退開始後250msで補正を0から通常値へS字状に増やす。前進と250ms以降の出力計算は維持。実際に出せる補正量へ制限してから増幅率を掛け、飽和で立ち上げ制限をすり抜けないようにした。補正の変化速度制限ではないため、センサー値の急変そのものは抑制しない。
- brake=1は逆相駆動から60msのショートブレーキへ変更した。brake=0は出力停止のみ。
- 他の走行関数の共通ゲイン・ブレーキ関数は変更していない。

実機調整前の初期値です。低出力10/30は以前の100と異なり、始動できない場合があります。短距離・長距離の前後進で停止距離と姿勢を比較してください。PWMの上限整形であり、実速度の閉ループ制御ではありません。
