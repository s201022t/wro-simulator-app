# 発進PWMの測定

FFの摩擦補償値を検討するため、停止状態から動き出すPWMを左右・前後別に測ります。速度比例FFの係数を求める測定ではありません。測定結果を設定へ自動保存する処理はありません。

## 使い方

1. `fresh_start` フォルダーで `pio run -e pico2_ff_calibration -t upload` を実行するか、PlatformIOの `pico2_ff_calibration` 環境のUploadを実行します。通常の `main.cpp` は編集不要です。
2. 115200bpsのシリアルモニターを開きます。
3. 通常の荷重・床面で、片輪駆動によって車体が旋回できる場所を確保します。車輪を浮かせた結果は無負荷時の参考値です。車輪を手で押さえないでください。
4. GP20ボタンを押して離すと、左前進→左後退→右前進→右後退を測定します。測定中にもう一度押すと中断します。
5. 最後の4行を記録し、ボタン操作で合計3回測ってください。

```text
LEFT_FORWARD=...
LEFT_REVERSE=...
RIGHT_FORWARD=...
RIGHT_REVERSE=...
```

測定モードでは `main.cpp` をビルド対象から除外し、`runProgram()` を実行しません。通常走行へ戻すときは `pio run -e pico2 -t upload` で通常版を書き戻します。既定のビルド環境は `pico2` のままです。共通のUploadボタンで通常版が選ばれる場合は、環境を明示した上記コマンドを使用してください。

## 測定条件

PWM・試行時間は `src/ff_calibration.cpp`、回転判定は `include/ff_motion_detector.h` で変更できます。開始時に `FF CALIBRATION v2 (sustained motion)` と表示される版を使用してください。

| 設定 | 初期値 | 意味 |
| --- | --- | --- |
| PWM_STEP | 5 | 5、10、15…の順に試す |
| MAX_TEST_PWM | 150 | 動かなくてもここで中止 |
| TEST_MS | 600ms | 各PWMを試す最大時間 |
| REST_MS | 700ms | 各試行前に出力OFFで待つ時間 |
| MOTION_COUNTS | 12 | 指令方向への正味移動量の下限（現在の換算で約3.76mm） |
| WINDOW_MS | 50ms | 回転継続を調べる間隔 |
| WINDOW_COUNTS | 2 | 各判定窓で指令方向に必要な正味カウント増分 |
| REQUIRED_WINDOWS | 3 | 条件を連続で満たす窓数（最低150ms） |
| REST_JITTER_COUNTS | 2 | 停止確認中に許容するカウントの最大値と最小値の差 |

各試行は一度出力を切ってから始めます。停止待ち後の100msは、カウントの最大値と最小値の差が2を超えると中止します。小さな揺れを許容しつつ、始点に戻る往復移動も監視します。出力OFFは位置保持ではないため、惰性で追加移動することがあります。

成功には「指令方向へ合計12カウント以上」と「50msごとに正味2カウント以上の進行が3窓連続」の両方が必要です。途中で止まる・逆戻りする・増分が足りない場合は連続窓数を0に戻します。一度だけ値が跳ね、その後止まる状態では成功しません。条件成立時は直ちに出力を切ります。反対輪または逆方向へ12カウント動いた場合は、連続判定を待たずエラー停止します。

記録値は「600ms以内に継続回転の条件を満たした最初のPWM」です。厳密な動き出しより高い値になる場合があり、正確な最小値や定常摩擦ではありません。時間・荷重・床・バッテリー状態に依存する5刻みの目安です。前後で異なる可能性があります。この値をそのまま常時加算すると強すぎる場合があるため、FF値は結果を確認して調整します。旧版の3カウント判定の測定値とは区別して記録してください。

## エラー時

- `other encoder moved`: 指令していない側のカウントが変化しました。エンコーダの左右対応、または床面からの力で反対輪も動いていないかを確認します。自動でピンを入れ替えることはしません。
- `encoder sign differs`: 指令方向とカウントの符号が逆です。前進で増える設定を確認します。
- `wheels still moving`: 停止待ち後も動いています。外力を除くか、REST_MSを延ばします。
- `no motion detected`: 上限まで動きを検出できませんでした。配線・カウント・負荷を確認します。この場合、150を測定結果として採用しません。

既存のエンコーダ設定は左GP28/29、右GP26/27です。実配線と違う場合は測定が中止されるため、表示されたdL/dRも確認してください。
