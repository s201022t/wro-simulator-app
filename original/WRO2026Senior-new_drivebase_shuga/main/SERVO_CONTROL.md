# サーボのS字制御

既存の `startServoMoveByPin`、`catchArm`、`liftArm`、`backArm`、
`circleArm` は、初期化後の移動でS字制御を使います。
サーボ用パルスの周期はServoライブラリの既定値（約20ms）、
パルス幅は従来どおり500～2500µsです。パルス幅の目標を5次曲線
`10t³ − 15t⁴ + 6t⁵` で補間し、始点・終点の指令速度と加速度をゼロにします。
軌道計算は最大500Hzで行います。500Hzはサーボのパルス周波数ではありません。

```cpp
liftArm(75, 180, 1);      // 速度180で上げ、指令の完了を待つ
catchArm(120, 200, 0);    // 速度200で開き始め、次へ進む
servoDelay(300);          // サーボ更新を続けながら300ms待つ
waitServoTasks();         // 全サーボの残りの軌道を待つ
```

速度は1～255に統一しました。省略値は255です。
旧コードの200、255はそれぞれ異なる速度になります。280の呼び出しは255に修正し、
外部から範囲外を指定した場合も1～255に制限します。
旧仕様の速度100は最大でしたが、新仕様では中程度の速度になります。

速度1～255は最大指令速度約33.3～500論理度/秒に対応します。
5次曲線の最大傾き1.875を使って移動時間を決め、短い移動でも最低100msを確保します。
例えば90論理度の移動は速度255で約338ms、200で約423msです。
実機の角度・速度とは必ずしも一致しません。調整箇所は `include/servo_s_curve.h` です。
加減速によって従来と移動時間が変わるため、走行と同時に動かす箇所は実機確認が必要です。

移動途中で指令を変更すると、最後に出力したパルス幅から新しい曲線を開始します。
位置指令は連続しますが、途中変更時の速度・加速度の連続性は保証しません。

初回接続とリセットは実位置が不明なので、初期パルスを直接指定します。
4引数の `attach()` により、意図しない中央パルスを先に出す処理をなくしました。
初期位置へ移動する動作そのものはS字ではありません。
`waitServoTasks()` は指令軌道の完了を待ち、実機の到達は検出しません。

既存の通常待機は `servoDelay()` に変更済みです。
追加する待機にもこれを使い、独自の長いループでは `updateServoTasks()` を呼んでください。
通信や独自処理で更新が長く途絶えると、その間は最後のパルスを保持し、
再開時に経過時間に対応した位置指令へ進みます。
`servoDelay()` 自体は停止ボタンを判定しません。既存の停止処理は維持し、
STOP確定時に軌道をキャンセルして保持指令にした後、従来どおり再起動します。

`test/test_servo_s_curve.cpp` はコンパイル時テストです。
両方向の単調性と範囲、緩やかな始終端、速度差、短距離、ゼロ距離、
経過時間超過、32bit時刻の周回、再指令の開始位置を検証します。
