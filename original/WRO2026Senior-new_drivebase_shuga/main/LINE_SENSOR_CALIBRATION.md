# ラインセンサの正規化

4センサをそれぞれ白=0、黒=1023に変換します。

`正規化値 = (生値 - 白の実測値) × 1023 / (黒の実測値 - 白の実測値)`

範囲外は0〜1023に制限します。黒の生値が白より小さいセンサにも対応します。

## 設定

2026-09-17の白・黒各100サンプルの平均（四捨五入）を起動時の初期値に設定済みです。次の呼び出しは初期値と同じ設定です。変更するときは`motionSetup()`の後、走行前に呼び出してください。

```cpp
setLineSensorCalibration(SENSOR_L_END, 518, 769); // 白、黒
setLineSensorCalibration(SENSOR_L,     459, 716);
setLineSensorCalibration(SENSOR_R,     474, 722);
setLineSensorCalibration(SENSOR_R_END, 513, 746);
```

関数で変更した設定はRAM上に保持されるため、その変更を使う場合は起動ごとに呼び出します。上記の初期値は自動的に適用されます。値をソースに固定したい場合は、motion_lib.cppのlineSensors配列内の初期値を編集できます。

高い生値を黒として校正済みです。実機での走行確認・PID調整は未実施です。不明なセンサピン、同じ白黒値、0〜1023の範囲外の設定はfalseを返し、それまでの設定を維持します。

## 測定・確認

ロボットを静止させて白い床と黒線でそれぞれ`checkline(20)`を実行します。各センサの`raw`（生値）を何回か見て代表値を設定してください。`normalized`は同じ測定値を正規化した値です。

`readLineSensor(SENSOR_L)`などで正規化値を取得できます。不明なピンには-1を返します。10bitのADC値（0〜1023）を前提としています。

ライントレースと端センサの黒線判定に適用済みです。校正すると左右差の大きさや黒線検出位置が変わるため、PIDゲインとEND_THRESHOLD（初期値840）は実機で再調整してください。
