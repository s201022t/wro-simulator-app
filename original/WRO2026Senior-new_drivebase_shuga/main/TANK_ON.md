# 距離指定なしの走行

`tankOn(power)` は走行を開始したらすぐ次のコードへ進みます。
スピードはPWM出力指定です。`tank()` の最高速は距離から自動計算されます。
正の値は前進、負の値は後退、0はオンモード停止です。
範囲外の値は -255〜255 に制限します。mm/sの指定ではありません。

```cpp
tankOn(150);       // 前進。エンコーダ同期＋ジャイロ補正が最初からON
servoDelay(500);   // 走行しながら500ms待機
tankSyncOn();     // 既にONなので何も変更しない（通常は省略可能）
servoDelay(1000);
tankSyncOff();    // 走行を続け、左右とも指定PWMの150に戻す
servoDelay(500);
tankOff();        // オンモードを終了し、出力を0にする

tankOn(-120);     // 後退。毎回、同期ONで開始
tankSyncOn();     // 後退でも同期可能
servoDelay(1000);
tankOff();
```

`tankSyncOn()`、`tankSyncOff()`、`tankOff()` は **tankOn動作中だけ有効** です。
他の走行関数の同期設定・出力は変更しません。
`tank()`、`line()` などがモーター制御を引き継ぐとオンモードは解除され、
それらの走行が終わっても自動再開しません。
競技シーケンス `runCurrentProgram()` の終了時にも `tankOff()` を呼びます。

同期には `tank()` と共通の左右エンコーダ補正＋ジャイロPD補正を使います。
`tankSyncOn()` 時点の向きを目標として、角度差と角速度を補正します。
係数・補正上限は `tank()` と共通です。後退時も方向に応じて補正します。
ジャイロが未準備、読取失敗、値が不正な場合はオンモードを停止します。
走行中の再キャリブレーションは行いません。
`tankSyncOff()` と片輪ブレーキはエンコーダ・ジャイロ両方の補正を解除します。
同期開始前の左右差は補正せず、オンにした時点から回転量をそろえます。
同期中の `tankSyncOn()` の再呼び出しでは基準位置を変更しません。
補正時は計算結果に応じて片側の出力を下げ、指定PWMの絶対値を超えず、逆転もしません。
同期なしでは左右同じPWMを出すだけなので、実際に真っすぐ走るとは限りません。
`tankOn()` を再度呼ぶと出力・方向を変更でき、その時点の向きを基準に同期ONで開始します。
同期なしで走らせたい場合は、`tankOn()` の直後に `tankSyncOff()` を呼びます。
開始時にジャイロが使えない場合は、モーターを駆動せずオンモードを解除します。
加減速処理はなく、`tankOff()` はPWMを0にする停止です。

同期とSTOPボタン監視は協調更新方式です。
`servoDelay()`、`updateServoTasks()` 内から自動更新されます。
独自の待機ループでは同じコアから `updateMotionTasks()` を定期的に呼んでください。

```cpp
tankOn(150);
tankSyncOn();
while (readLineSensor(SENSOR_L) < 500) {
  updateServoTasks(); // モーター同期・STOP監視とサーボを更新
}
tankOff();
```

通常の `delay()` や更新関数を呼ばない長い処理中は、最後のPWMで走り続け、
同期補正とSTOP監視は更新されません。待機には `servoDelay()` を使ってください。
実機での速度・同期補正の調整は別途必要です。

## 片輪の逆位相ブレーキ

`tankBrakeLeft()` は左輪、`tankBrakeRight()` は右輪だけに適用します。
どちらもtankOn動作中だけ有効で、他の走行関数には作用しません。

```cpp
tankOn(150);
tankSyncOn();
servoDelay(500);
tankBrakeLeft();  // 左輪を逆位相で制動。同期解除、右輪は走行継続
servoDelay(300);  // 左輪のPWMは0のまま
tankOff();        // 両輪の出力0。オンモード・同期・片輪ブレーキ状態を解除
tank(300);   // 通常のtankを実行できる

tankOn(-120);
servoDelay(500);
tankBrakeRight(); // 後退中の右輪も制動できる
tankOff();
```

ブレーキ関数は、最初に5msのエンコーダ変化で回転方向を確認します。
動いていれば対象輪の直前PWMと同じ強さを逆方向へ出します。
5msごとの変化量が±1パルス以内、または計測した方向と逆になったら
対象輪の出力を0にします。逆出力は最大100ms、関数全体は最大約105msです。
サーボとSTOP監視はこの待機中も更新します。

対象輪は次のtankOnまで再駆動しません。片輪停止中のtankSyncOnは無効で、
tankSyncOffでも停止輪は再駆動しません。反対輪はブレーキ開始時のPWMを維持し、
tankSyncOffを呼ぶとその輪はtankOnで指定したPWMに戻ります。
tankOffまたは他の走行関数への切り替えで、片輪ブレーキ状態も解除します。
これは制動後にPWMを0にする動作で、停止位置を保持する制御ではありません。
エンコーダによる判定とタイムアウトは停止を保証するものではなく、実機確認が必要です。
