# WRO 2026 Senior ロボットシミュレーター

MOTION2350 Pro 用の既存 C++ 制御コードを、仮想 Arduino ハードウェアと差動二輪モデル上で実行するローカルシミュレーターです。`original/` 内の実機コードは変更せず、`main/src/motion_lib.cpp` をネイティブエンジンへ直接リンクしています。

## 現在動作する範囲

- 元の `tank()`、`spin()`、`tline()`、`servo_lib.cpp`、`pi_color_lib.cpp` を直接実行
- PWM 出力から左右車輪速度、位置、姿勢を固定仮想時間で計算
- A/B 相の状態を生成し、元コードが登録したエンコーダ割り込みを実行
- MPU9265 の `WHO_AM_I` と Z 軸角速度を Wire1 のレジスタ通信で提供
- ロボット位置に基づく4個の仮想ラインセンサー
- 日本語 GUI、軌跡、PWM グラフ、ログ、JSON 保存、リプレイ
- 72個の競技オブジェクト、ドラッグ配置、押し出し、簡易把持・運搬・解放
- `runCurrentProgram()`、section A〜C、extra 1〜10 の選択
- 公式フィールド画像のローカル読み込みとブラウザキャッシュ
- Linux と Windows 用 CMake ビルド設定

## 必要環境と起動

Node.js 20 以上と C++20 コンパイラが必要です。

```bash
npm run build:native
npm start
```

ブラウザで `http://127.0.0.1:4173` を開きます。外部サーバーや有料 API は使いません。CMake を使う場合：

```bash
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

Windows では Visual Studio 2022 の Developer PowerShell で CMake コマンドを実行し、その後 `npm start` を実行します。現在はインストーラー形式ではなく、ネイティブ実行ファイルとローカル UI の構成です。

Electron デスクトップ版は `npm install` 後に `npm run desktop` で起動できます。Windows portable EXE は `npm run dist:win` で生成します。GitHub Actions の Windows ジョブでも同じ成果物を作成します。

## 操作と公式フィールド

上部でデモを選び「実行」を押します。標準デモは元の関数を使って `tank(300) → spin(90) → tank(300) → tankOff()` を実行します。競技用 `runCurrentProgram()` は変更していません。

左パネルから公式マットの PNG/JPEG を読み込めます。公式 PDF は再配布していないため、PDF を画像に書き出して読み込んでください。画像はブラウザ内に保存されます。フィールド座標は 2362 × 1143 mm です。

## テスト

```bash
npm test
```

ネイティブ実行ファイルを起動し、元の `tank()` / `spin()` が仮想 PWM、エンコーダ、ジャイロを介して物理状態を更新することを確認します。

## パラメータと校正

ソース由来の初期値は車輪径 62.4 mm、トレッド 167.0 mm、エンコーダ 620 count/rev です。最大車輪速度 900 mm/s とモーター時定数 80 ms は仮設定で、`simulator/native/virtual_arduino.cpp` にあります。実機で一定 PWM ごとの走行距離、旋回角、停止距離を測り、最大速度・時定数・左右差を合わせてください。

## 既知の制約

- 公式マット、公式オブジェクト寸法、得点規則は同梱していません。内蔵表示は明示された概略図です。
- オブジェクトは円形近似による押し出し・把持です。厳密な剛体回転、公式採点、正式寸法のアーム形状は未実装です。
- GUI の一時停止・ステップは受信済み状態の表示制御です。ネイティブ制御スレッド自体の停止ではありません。
- GUI からの C++ 編集・再コンパイルは未実装です。
- ラインモデルは概略グリッドです。公式画像の画素色をセンサー入力へ使う処理は未実装です。
- MPU ノイズ・ドリフトと車輪スリップはまだ導入していません。
- 元のサーボ S 字タスクと色認識パーサーは直接リンク済みです。カメラ光学モデルはフィールド座標を使う簡易モデルです。
- 元コードでは GP26–29 がラインセンサーとエンコーダの双方に割り当てられています。実機コードの GPIO は変更していません。
- Windows 用設定は用意していますが、この Linux 環境では Windows 実行確認をしていません。

実機との差は床、電池、個体差、荷重でも変わります。本シミュレーターの結果は大会の公式判定や実機挙動を保証しません。
